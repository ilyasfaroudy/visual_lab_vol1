# Демонстрация с телефона

1. Подключите компьютер и телефон к одной Wi-Fi сети.
2. Запустите START_MOBILE.cmd. Не закрывайте окно сервера.
3. Откройте на телефоне адрес из строки «SEKRET LAB v4 running at». Это реальный частный IP компьютера и выбранный свободный порт. 127.0.0.1 на телефоне не подходит.
4. Если Windows спросит, разрешите Node.js доступ только к частной сети. Настройки Firewall автоматически не меняются. Гостевая Wi-Fi сеть может запрещать связь между устройствами.
5. Откройте Audio Lab → SYSTEMS → выберите эффект → PREVIEW. Demo Signal включается явно. SETTINGS открывает половину экрана; кнопка сверху раскрывает панель и закрывает её.
6. Для музыки: LOAD AUDIO / VIDEO, выберите файл на телефоне, затем нажмите Play. AUTO SENSITIVITY и профили находятся в AUDIO REACTIVITY.

HTTP в локальной сети подходит для Demo Signal и загрузки файлов. Микрофон может требовать HTTPS; он не нужен для показа. Звук запускается касанием. Экспорт/полный экран зависят от мобильного браузера. Физический телефон этой итерацией не проверен.

Сервер слушает только выбранный частный IPv4-интерфейс. Он не публикует проект в интернет и не меняет настройки роутера. Если у компьютера несколько адаптеров/VPN, проверьте напечатанные LAN IP и подключение к той же сети.
